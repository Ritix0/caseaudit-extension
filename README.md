# Протокол «Народный Аудитор Кейсов» — Browser Extension (v1.2.0)

Официальное браузерное расширение для независимого децентрализованного аудита, фиксации реальной отдачи (RTP) и разоблачения манипуляций вероятностями на популярных кейс-площадках: Case-Battle, MyCS2 и EasyDrop.

## 🛡️ Безопасность и 100% Анонимность (GDPR Compliant)
Расширение спроектировано по строгим стандартам безопасности и не собирает никаких личных данных:
* **БЕЗ авторизации через Steam:** Расширение не требует ввода ваших учетных данных и не имеет доступа к вашим Steam-сессиям, паролям или мобильному аутентификатору (Steam Guard).
* **БЕЗ сбора личных данных:** Мы категорически не собираем ваши куки, историю браузера, платежные реквизиты или IP-адреса.
* **Сухая статистика:** В базу данных шлюза передаются исключительно анонимные параметры совершенных транзакций (затраты на открытие/апгрейд, стоимость выпавшего предмета, тип операции и название кейса).

## 📥 Инструкция по ручной установке расширения (за 10 секунд)

Поскольку расширение распространяется по децентрализованной модели без цензуры со стороны сторов, установка выполняется вручную в режиме разработчика:

1. Перейдите в наш официальный Telegram-канал по ссылке ниже и скачайте актуальный ZIP-архив с расширением: **[Вступить в Telegram](https://t.me/caseaudit_protocol)**.
2. Распакуйте скачанный ZIP-архив в любую удобную папку на вашем компьютере.
3. Откройте ваш браузер на базе Chromium (Google Chrome, Яндекс.Браузер, Opera, Microsoft Edge) и перейдите по адресу: `chrome://extensions/`
4. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
5. В левом верхнем углу нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).
6. Выберите распакованную папку из Шага 2.
7. Расширение установлено. Закрепите иконку аудитора на панели задач вашего браузера, откройте её и введите ваш персональный ID профиля для отслеживания личной статистики на нашем портале!
